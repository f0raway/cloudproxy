# 实时连接监控

## 访问

监控由入口服务器提供，无需更改 SCF 云函数，不产生额外的云函数调用。默认地址由 `dashboard_addr` 决定（模板为 `127.0.0.1:8081`）。通过 SSH 转发后在浏览器打开：

```bash
ssh -L 18081:127.0.0.1:8081 your-user@your-server
```

访问 `http://127.0.0.1:18081`，输入现有代理 `user` / `password`。页面、`GET /api/stats` 和 `GET /api/connections` 均需认证。不要将接口直接暴露至公网；内网直接访问也需要可信网络/VPN，HTTP Basic 自身不加密。

## 记录机制

SOCKS5 在接受客户端 TCP socket 时创建记录，因此尚未完成认证和认证失败也可见。握手最多等待 15 秒。请求解析后填入目标，等待入口连接槽位，云节点故障时最多尝试两个不同区域；目标错误则在本地进入指数退避，不立即换区。只有收到云节点目标 TCP 建连成功确认后才标记“已连接”。成功连接不切换区域、不重建 TCP。

CONNECT 在入口收到请求时记录来源与目标，HTTP 在每次请求时单独记录。普通 HTTP 仍复用既有连接池：通过 `httptrace.GotConn` 关联实际隧道区域，来源始终来自当前请求，不复用上一客户端的身份。普通 HTTP 的多次请求与“启动以来已建立隧道”次数不一定相同。

区域尝试保留时间、区域、失败原文。先失败后换区成功的记录保持成功状态，详情保留之前失败的尝试。最终错误区分目标连接、认证、并发/预算保护、私网拒绝、无可用节点及传输中断；空闲 120 秒、最大时长 7,200 秒、预算不足和服务停止会显示相应原因。目标 HTTP 状态码另行记录，HTTP 500 表示已取得响应，不等同隧道连接失败。

上传表示客户端向目标方向，下载反向。SOCKS5/CONNECT 按隧道字节计算，不含 SOCKS/CONNECT/WSS 握手封装；HTTP 按请求/响应正文计算，不含头部。它们不是腾讯云计费流量。服务器仅能观察 TCP/WSS 错误，无法解密或诊断透传 TLS 内的应用错误；客户端主动断开也可能被记录为传输中断。

## 界面与接口

每 2 秒轮询两个本地接口。可按协议、状态、来源、目标、区域和错误筛选，暂停后停止轮询。点击或按 Enter 打开行详情。接口不可用时，红色提示明确标记数据为上次快照；不会将旧数据显示为正常运行。

`/api/connections` 返回 `connections` 数组及 `active`、`history_limit`、`omitted`、`server_time`。每行包含：

| 字段 | 含义 |
| --- | --- |
| `id` | 递增编号；启用日志恢复后接续已恢复记录的最大编号 |
| `source` / `target` | 对端与目标的主机:端口 |
| `protocol` / `region` | 代理协议与实际选区 |
| `state` | negotiating / queued / connecting / connected / closed / failed |
| `started` / `connected` / `ended` | 起始、成功建连、结束的服务器时间 |
| `uploaded` / `downloaded` | 上述口径的累计字节 |
| `error` / `attempts` | 最终错误与逐次区域尝试 |
| `error_category` / `diagnosis` | 本地拒绝、客户端断开、目标/节点错误等分类与诊断 |
| `http_status` | 普通 HTTP 的目标响应码（若已取得） |

快照按活跃优先、编号倒序排列，所有活跃记录和最近 1,000 条结束记录可查。界面仅呈现筛选后的前 200 条，缩小筛选范围可找更早记录。最多保留 256 条未结束记录（含握手），超过时拒绝新增连接并递增 `omitted`，避免未认证连接撑爆监控内存；页面会提示。现有最多 64 条隧道与 5 秒排队保护仍然生效。

## 隐私与边界

- 来源是入口实际看到的地址，经过 NAT 时可能是网关；无法得到 Proxifier 所见的 `chrome.exe` 等本地进程名。
- 目标按客户端提供的域名/IP记录，不伪造解析结果或出口 IP。客户端若只提交 IP，就不会凭空出现域名。
- 不保存完整 URL、路径、查询、Cookie、正文或认证头。错误中替换已配置的代理密码、节点令牌和完整节点地址；使用文本节点呈现，避免目标/错误被当作 HTML 执行。
- 连接历史默认写入有大小上限的本地结构化日志，重启可恢复最近 1,000 条结束记录；可在配置页关闭。日志不写入费用账本，不向外部分析服务上传。详见 [日志与诊断](LOGGING.md)。
- 两个 JSON 接口和页面均禁止缓存。页面不引用外部脚本、字体或样式，嵌入 Go 二进制即可部署。

## 升级

```bash
bash ops/build.sh
sudo bash ops/install.sh dist/scf-tunnel-linux-amd64 /path/to/private/agent.json
```

通用安装器会更新二进制与健康检查。已有定制部署请保留自己的服务名称、配置路径、账号密码、节点和费用账本；备份旧二进制后，只替换入口二进制，并让健康检查使用配置中的账号密码访问 `/api/stats`。未更新健康检查前不要重启旧定时器，否则 401 会触发误重启。无需重新创建或部署云节点。

升级重启会中断现有连接；随后新连接开始进入明细。原版没有连接历史，所以无法回溯升级前发生的连接。

多平台页面中的区域列为节点配置的区域或名称标签，不是实测的出口 IP/国家。免费节点实际出口由平台分配，不能从标签推断每次换 IP 或国家。配置方法见 [页面配置](SETTINGS.md)。
