# 日志与诊断

监控页展示来源地址、目标主机/端口、连接时间、节点尝试、收发字节及错误。它不能获取客户端进程名称，也不读取 HTTPS 正文。建立 TCP 隧道不代表目标网页或业务请求成功。

## 保留与配置

配置页“日志与节点网络”可开关连接日志、设置每个文件 1–100 MiB、保留 0–5 个旧文件。默认开启，每文件 5 MiB，2 个旧文件。两类日志分别为账本所在目录的 `service.log` 和 `connections.jsonl`，默认合计上限约 30 MiB；升级备份、账本和 systemd 启动日志另计。文件权限 600，目录应仅服务用户访问。

写入前检查大小，自动轮转；下调上限时按完整行保留尾部。关闭连接日志停止新增连接事件，现有文件和内存监控记录仍保留。运行错误日志仍记录。内存保留最新 1,000 条结束记录，启动时从现有连接日志恢复；活跃记录单独显示。恢复不会把缺少结束事件的旧连接显示成仍活跃。

连接建立和结束各写一条结构化事件。容量 512 的异步队列在满载时丢弃日志而不阻塞转发，监控页显示丢弃和写入错误计数。队列不保证断电或崩溃时持久化，计数在重启后重新开始。运行日志为同步写入，重复 SOCKS 错误按分钟限量汇总。

日志不包含请求路径、正文和认证头；已知密码、节点令牌和节点 URL 会脱敏，但来源、目的地址、时间和流量仍属于敏感连接元数据。不要将实际日志提交到公开仓库。

## 怎样判断问题

- **目标 / 节点错误**：查看每次节点尝试、最后错误、是否曾建立连接。目标拒绝连接与节点断线需要分别排查。
- **本地拒绝 / 保护**：包括非公网目标、配置范围、费用限制、退避和并发限制。此类拒绝不等于一次新的云端连接失败。
- **客户端认证 / 断开**：客户端在提交目标前关闭连接（包括认证后、尚未发送 CONNECT 请求的 EOF）单独归类，不算节点故障，也未调用云节点；已提交目标后的上游 EOF 仍按实际传输错误记录。
- **当前平台不可达**：节点报告无法连接此目标，不等于平台整体故障。平台能力限制或该路径不可达均有可能，应结合尝试详情判断。
- **目标网络不可达**：云节点无法路由到客户端提交的 IPv6 目标时明确提示。入口的 `node_network` 不会将 IPv6 目标转换为 IPv4。
- **连接已结束**：字节收发说明发生过传输，不能证明应用层响应正确；应同时检查客户端结果。

`198.18.0.0/15` 是非公网地址，常见于 Fake-IP DNS 映射。若客户端将这类 IP 交给远程节点，节点无法还原原始域名；应检查本地 DNS/代理链，让 SOCKS 请求携带原始域名，而非放开保留地址限制。

## 节点网络与回退

`node_network` 可设 `auto`、`ipv4`、`ipv6`，仅控制入口服务器到云节点的网络，不改变目标范围与云端目标解析。在无 IPv6 出口的服务器上可以选择 IPv4。

Cloudflare 对某目标连接失败后，该目标的免费路径逐步退避 30、60、120、240、480、600 秒；长时间未失败后重新计数。腾讯云成功不会清除免费路径的失败计数，免费路径成功才清除自身记录。明确不支持的目标采用独立退避。预算、目标限制和是否允许付费回退仍然生效；回退可能产生费用，日志功能不保证降低账单。

没有可用节点时，错误列会列出已停用、付费回退关闭、目标平台退避、节点冷却和每日额度等原因及数量（每节点按首个适用原因计数）。页面同时显示当前实际启用的收费节点数；允许付费回退不代表存在已启用的付费节点。
