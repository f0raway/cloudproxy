# 页面配置与目标范围

使用现有账号登录监控页，进入 **配置管理**。页面可编辑账号密码、月度保护上限、平台调度、Cloudflare 每日请求限额、目标范围、节点列表/启停、节点令牌和单价。

保存前服务端完整校验，配置以权限 600 原子写入费用账本旁 `settings.json`，随后更新内存配置。可通过基础配置的 `settings_path` 指定其他路径，服务用户必须有写权限。基础配置中的入口地址、费用账本、项目默认节点令牌、账单缓存路径不能由这个接口修改。

密码留空保留旧值；同一 URL 的节点令牌留空也保留旧值，新 URL 不填则使用基础配置项目令牌。网页读取接口不返回已保存密码/令牌。改变账号后需要刷新并用新账号重新登录，客户端的代理认证也需对应更新；已认证 TCP 连接不会因此被主动重建。网页管理和代理共用账号，勿将该账号分享给不可信使用者。

## 目标规则

- 允许规则留空：允许所有通过公网地址检查的目标。否则至少匹配一条。
- 拒绝规则优先于允许规则。
- `api.example.com` 仅匹配该域名；`*.example.com` 匹配子域名，不包含 `example.com` 本身。
- IP 与 CIDR 仅匹配客户端直接提交的 IP（IPv4-mapped IPv6 规范化为 IPv4）；入口不为匹配 CIDR 而解析域名，避免改变远程 DNS 行为。
- 允许端口留空不额外限制，否则只允许指定端口。不要在域名规则里附带路径、URL 或端口。
- 私网、保留、文档、基准测试等非公网地址始终拒绝，不能通过允许规则打开。`198.18.x.x` 的 Fake-IP 需要客户端提交对应域名，服务器不能还原客户端的映射。

规则按新建连接校验，不是对现有加密连接内容的检查，不会为了应用新规则强制切断所有旧连接。若需立即撤销会话应由管理员停止入口服务。

## 平台与费用

`routing_strategy` 为 `free_first` 或 `round_robin`；`paid_fallback_disabled=true` 时，只允许新连接使用 Cloudflare 免费节点，没有可用免费节点则本地拒绝，不暗中转去付费节点。这个开关不停止已经建立的付费连接。

Cloudflare `cloudflare_daily_limit` 默认 90,000，可设 0–100,000；0 表示不再创建 Cloudflare 连接。`quota_group` 标识共享额度组，同一 Cloudflare 账号的全部节点必须使用同组。默认没有组名的 Cloudflare 节点保守共用 `cloudflare` 组。当天尝试计数写入 `provider-daily-usage.json`，UTC 换日，失败尝试也保守计数。

本地限额不等于云账号剩余额度，不覆盖其他 Worker/直接访问，不能保证不受账号日限额或平台 CPU 限制影响。Cloudflare 的零时长本地费率仅适用于选择 Workers Free 适配；已有付费订阅的固定费用不受本程序控制。

免费 Cloudflare 节点报告目标 DNS/TCP 错误且允许付费回退时，会再尝试一次付费节点，并将该目标的免费路径按连续失败次数退避 30、60、120、240、480、600 秒；付费路径成功不会清除免费路径的失败计数；付费节点本身的目标错误不继续跨区域重试。平台明确不支持目标时，免费路径缓存 10 分钟。关闭付费回退后不会执行这些付费尝试。

腾讯云默认费率适用于既有 128MB 部署；可在节点中指定 `rates`：

```json
{"compute_yuan_per_second":0.000013885,"traffic_yuan_per_gb":0.8,"request_yuan":0.00000133}
```

费用单位为人民币。流量沿用双倍字节保守估算。其他平台 `provider=custom` 必须明确填写费率；它不是免费平台。价格设置只影响本地估算，不能改变云平台收费。所有付费节点共用 `monthly_limit_yuan` 保护，不自动提升该上限。

## 接口

- `GET /api/settings`：认证后返回可编辑设置及进程内 CSRF token，密码/节点令牌不返回。
- `POST /api/settings`：要求相同认证、`Content-Type: application/json` 和 `X-CSRF-Token`；若存在 Origin，必须与本页面 Host 相同。未知字段、非法预算、非法节点、超额日限额及无效目标规则均拒绝，原配置保留。
- 变更涉及配置覆盖、内存和日志保留参数，不清空费用账本和日限额计数，不自动开通任何云平台资源。
